# 🚀 About The Project

Gesture Hologram AI PRO is a futuristic AI-powered 3D hologram system built using Python, OpenCV, MediaPipe, OpenGL, and Pygame.

The project allows users to interact with multiple 3D holographic objects in real-time using hand gestures such as swipe, pinch, open palm, and movement tracking.

Inspired by Iron Man / JARVIS style interfaces, this system creates an immersive hologram-like experience directly from a webcam.

# 🖐️ Gesture Controls

| Gesture | Action |
|---|---|
| 👋 Move Hand | Rotate Object |
| 🤏 Pinch | Zoom In / Out |
| 👉 Swipe Right | Next Object |
| 👈 Swipe Left | Previous Object |
| 🖐️ Open Palm | Auto Rotate |
